Verify Bcrypt Hash

Paste the original values and their bcrypt hashes in matching line order. Each line in the first box is checked against the same line in the second box.

Privacy: Hashing is performed in this browser using bcryptjs; your input values are not sent to a server. The bcrypt library is loaded from a CDN, so an internet connection is needed when opening this page. Each value gets its own random salt, so hashing the same value again normally produces a different hash. Bcrypt is one-way hashing, not reversible encryption.
